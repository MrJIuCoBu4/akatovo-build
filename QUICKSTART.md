# У леса — запуск и устройство проекта

Это полные исходники актуального интерактивного плана. Приложение статическое: HTML, CSS и JavaScript ES-модули. Устанавливать зависимости или выполнять сборку не нужно.

Интерфейс — студийный редактор участка: слева инструменты и зоны, в центре план, справа инспектор свойств, внизу метрики. Функциональные зоны (двор, лесная кромка, въезд, буфер) вычисляются из модели как ориентиры и не являются геодезической разбивкой.

Актуальные исходники в `dist/assets/`: контур со сегментами границ и отступами 1/3 м, эскиз ГП-01 / РЕВ. 03 (05.10.2026), компас 215° для Акатово парк (г. Клин, д. Акатово, владение 200), фото и видео площадки 03–07.10.2026 (расчистка, въезд/дренаж, лесная кромка). Подробности — вкладка «Данные».

## Запуск на Windows

1. Распакуйте архив и откройте терминал в папке `forest-plot-planner`.
2. Если установлен Python, выполните:

```powershell
py -m http.server 8000 --bind 127.0.0.1 --directory dist
```

3. Откройте http://localhost:8000 в браузере. Сервер доступен только на вашем компьютере.
4. Для остановки нажмите Ctrl+C в терминале.

На macOS/Linux команда аналогична:

```sh
python3 -m http.server 8000 --bind 127.0.0.1 --directory dist
```

Если Python не установлен, подойдет любой локальный статический HTTP-сервер с корнем `dist`. Прямое открытие `index.html` через `file://` может блокировать ES-модули: запускайте через HTTP.

## Где что находится

- `dist/index.html` — интерфейс и тексты.
- `dist/styles.css` — оформление и адаптивная верстка.
- `dist/app.js` — редактирование объектов, сравнение, сохранение и импорт/экспорт.
- `dist/geometry.js` — геометрия участка, объектов, дорожки и проверки пересечений.
- `dist/scene.js` — SVG-план, направление солнца и проекции теней.
- `dist/solar.js` — приблизительный расчет положения солнца.
- `dist/assets/` — исходные фотографии и схемы.
- `tests/` — проверки геометрии и интерфейсной логики.

Для запуска проверок нужен Node.js. В корне проекта выполните:

```sh
npm run check
```

`npm install` не требуется: внешних пакетов нет. Проверки используют встроенный `node:test`.

## Перенос ваших вариантов

План сохраняется в localStorage конкретного браузера и адреса сайта. Архив содержит исходники и начальный план; ваши изменения на размещенном сайте не попадают в исходники автоматически.

Чтобы перенести их в локальную копию, на исходном сайте откройте «Исходные данные» → «Скачать варианты (.json)», затем в локальной копии нажмите «Загрузить варианты». JSON переносит объекты, дорожку, сохраненные варианты и настройки солнца.

## Приватность

Приложение не содержит серверной части, базы данных, аналитики или внешних сетевых запросов. Локальный запуск ничего не публикует. Архив содержит личные фотографии и схемы участка: доступ к ним определяется тем, кому вы передадите архив или где разместите его содержимое.

## Точность модели

Геометрия участка восстановлена по рисунку, а не по геодезии. Солнечная модель использует координаты 56.098333° N, 36.595° E и московское время UTC+3. Тени приближенные: ровная земля, заданные высоты объектов и равномерная полоса леса. Подробности и допущения указаны в README.md и интерфейсе.
